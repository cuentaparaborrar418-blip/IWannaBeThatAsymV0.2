IWannaBeThatAsym
=================

Para iniciar el juego:
1. Abre "Game Starter.bat".
2. Se iniciará un servidor local temporal.
3. El juego se abrirá automáticamente en tu navegador.

El servidor es SOLO local (127.0.0.1), no sube el juego a Internet.
El servidor se cierra automáticamente después de un máximo de 2 horas.

IMPORTANTE:
- Se conservaron los archivos originales del juego y su orden de carga.
- No se cambió la lógica del gameplay.
- El juego usa Tailwind desde su CDN, así que para conservar exactamente su apariencia original necesita conexión a Internet al cargar la página.
